# Drive Circuit

Real-time F1-style racing game built in C++ with OpenGL 4.0 and GLSL shaders.

## Features
- Catmull-Rom spline circuit with arc-length parameterisation
- Four camera modes — free, first person, third person, top view
- Day / Night / Storm modes with GLSL fog, rain streaks and lightning shaders
- 40 animated diamond lane markers with per-marker spin and bob
- Collision-based barrel pickup system with lap timer
- Drop shadow HUD rendered with FreeType

## Tech Stack
C++ · OpenGL 4.0 · GLSL · Assimp · FreeType · GLM · Visual Studio
